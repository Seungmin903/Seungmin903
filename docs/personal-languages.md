# 개인 기여 언어 통계

2026-11-27 스냅샷. 저장소 전체 크기가 아니라 현재 소스 파일에서 본인에게 귀속된 비어 있지 않은 줄 수를 언어별로 합산했습니다. 주석 줄은 소스의 일부로 포함합니다.

- `git blame --root`의 작성자 이메일 및 확인된 본인 이름을 사용합니다. GitHub 계정과 연결된 이메일은 API의 커밋 작성자 정보로 확인했습니다.
- DIO·MICON·EMOUR는 팀원별 작성 이력을 보존한 로컬 원본 저장소의 커밋 스냅샷을 사용했습니다. 나머지는 조회 당시 GitHub 기본 브랜치 스냅샷을 사용했습니다. 미커밋 변경은 포함하지 않습니다.
- CodingTest는 기본 브랜치의 전체 321개 커밋 작성자가 본인임을 확인한 후 현재 소스 파일을 집계했습니다. TradingGame은 확인된 본인 작성 커밋이 없어 포함하지 않았습니다.
- Fork에서도 본인이 작성한 줄은 포함하고 다른 작성자에게 귀속된 줄은 제외합니다. 동일한 저장소는 한 번만 집계합니다.
- 인식하는 언어의 소스 확장자만 집계합니다. 이미지·SVG·README·JSON·잠금 파일·Gradle 래퍼·타입 선언·축소 번들, 생성·빌드·외부 라이브러리 디렉터리는 제외합니다. Git의 `linguist-generated`, `linguist-vendored`, `linguist-detectable` 속성도 적용합니다.
- Git 기록상 작성자를 집계하는 지표입니다. AI 사용 여부, 실제 타이핑 시간, 설계·리뷰 기여도는 구분하지 않습니다. Squash·코드 이동·복사와 작성자 변경에 따라 귀속이 달라질 수 있습니다. 작성 이력이 없는 외부 코드까지 완벽하게 식별한다는 의미는 아닙니다.
- 자동 갱신하지 않습니다. 다시 분석하면 새 스냅샷으로 교체할 수 있습니다.
